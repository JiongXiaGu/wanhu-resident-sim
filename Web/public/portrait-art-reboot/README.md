# Art Reboot proof assets

The files in this folder are isolated art-direction studies, not production portrait modules.

`painted.avif` contains five 192 × 192 concept-art crops produced during this task's generative visual exploration. The paper background and original crown-top crop are baked in. Do not upscale it and call it a production master or extract it into interchangeable Face/Hair/Outfit layers.

`graphic.svg` and `clay.svg` are newly authored vector drawings. Each named group (`woman`, `man`, `elder`, `noble`, `sovereign`) occupies one 320 × 320 cell; the sheet offset is an export/layout choice, not a character fitting system. `clay.svg` depicts volume using 2.5D vector shading; no underlying mesh or bake pipeline is supplied.

No production paths, old A–F paths, external image hosts or third-party portrait packs are used. The corresponding page is `/?view=portrait-art-reboot`; art and technical boundaries are recorded in `Documentation/Portrait Art Reboot.md`.
