# 居民头像身份化生成设计 V2

## 目标

本阶段仍只服务 Web 玩法原型。目标从“随机头像是否足够多”推进到“玩家能否仅凭头像快速读出居民的大致身份”。

当前重点验证：

1. 女性居民是否形成稳定、可辨认的视觉语言，而不是只把男性头像换一个发髻；
2. 官署、书生、商贸、手艺、医护等身份是否有弱而明确的服饰差异；
3. 同一身份内部仍保留足够随机性，不形成“一职业一张固定头像”；
4. PortraitRig V2 的装配规则继续保持稳定，不因新增身份资源重新产生错位。

## 输入事实

V2 不新增一套独立的“身份存档数据”。头像 Resolver 直接使用已有居民事实：

```text
Gender
LifeStage
OccupationId
OccupationGroupId
AppearanceDNA Seed / 权重
```

当前身份约束主要来自 `Gender + OccupationGroup`。Web 原型后续如果需要验证财富、婚姻或社会地位对外观的影响，再增加轻量 Profile；现在不提前设计 Unity Save 或 Runtime 字段。

## 生成流程

```text
Resident Facts
↓
Identity Candidate Filter
↓
Face Family / PortraitRig
↓
Compatibility Weight
↓
AppearanceDNA
↓
Layer Renderer
```

其中：

- 性别与年龄负责生理合理性；
- 职业组负责身份提示；
- Face Family 与 PortraitRig 负责装配；
- Weight 负责同身份内部的变化；
- AppearanceDNA 仍然是最终头像身份。

## 女性角色规则

女性角色不是单独生成完整头像，而是在相同 PortraitRig 框架下拥有更有针对性的候选池。

当前第一批增加：

- 女子椭圆脸、圆脸、长脸、成熟脸；
- 提高女性发髻、低髻等发型权重；
- 女子劳作布巾、市井小帽、遮阳笠；
- 女子城中常服、女掌柜常服、女子劳作短衣、女子医护常服、女子戏班便服。

硬规则继续保持：

```text
female → facialHair = none
child / teen → facialHair = none
```

女性外观的目标是“人物类型成立”，不是刻意夸大性别特征。

## 官署与书生

新增职业组：

```text
occupation-group.administration
```

第一批身份：

- 书吏
- 官员

同时在学业组增加成年书生，用来区分“学生”和“成年读书人”。

头像层提供：

```text
官署正帽
书吏小帽
书吏公服
官员公服
书生长衫
```

由于《万户天工》采用泛中国古代语境，当前服饰只表达“正式、文职、官署”这一层级，不绑定某一具体朝代的严格品级制度，也不使用需要精确考据的品级纹章。

## 身份强度

身份影响应当是弱约束而不是绝对绑定。

推荐理解：

```text
普通外观随机
+
身份候选池 / 权重偏置
+
少量专属部件
```

例如：

- 官员应明显比普通百姓正式，但不同官员仍可有不同脸型、发型、胡须和配色；
- 女掌柜可以比普通小贩更整洁，但不需要固定同一套衣服；
- 书生应有文气服装与头饰倾向，但不是所有教育组居民都穿一样。

## Portrait Lab V3

访问：

```text
/?view=portraits
```

V3 仍保留 64 个样本，但前 8 个样本固定覆盖：

- 官署男性 × 2
- 书生男性 × 1
- 女商贸 × 2
- 女手艺 × 1
- 女医护 × 1
- 女农事 × 1

其余继续随机。

这样头像实验室既能看总体随机分布，也不会因为官员本来就稀少而每次都抽不到需要检查的身份。

新增筛选：

```text
身份：全部 / 官署 / 学业 / 商贸 / 手艺 / 医护
```

每张卡片同时显示：

```text
性别 · 职业组 · 是否为覆盖样本
```

## 美术生产建议

正式美术仍按 Portrait Art Kit 生产，而不是画大量完整头像。

身份化后，美术资源可以按下面的目录思路整理：

```text
Faces/
Hair/
Headwear/
  Common/
  Work/
  Trade/
  Scholar/
  Administration/
Outfits/
  Common/
  Female/
  Work/
  Trade/
  Scholar/
  Administration/
```

同一身份优先通过轮廓、头饰、领口、肩部和整体配色建立辨识度，不依赖微小纹样。

## 验收标准

第一阶段通过条件：

1. 64 人里女性角色不是清一色同一张脸或同一发髻；
2. 官署样本第一眼比普通商贩、工匠更正式；
3. 书生和官署角色可以区分；
4. 女商贩、女工匠、女医护仍保留职业提示；
5. 所有新增部件继续通过 PortraitRig V2 的硬装配检查；
6. 同身份内部至少保留 Face / Hair / Brow / Palette 等多维随机变化。

## Unity 迁移边界

这份设计只定义可复用语义：

```text
AppearanceDNA
Gender / LifeStage / OccupationGroup 对外观的约束
PortraitRig 锚点
Headwear 遮挡规则
身份化美术分类
```

未来进入 Unity 后，Sprite、Mesh、Material、ECS、缓存和存档结构全部重新设计。
