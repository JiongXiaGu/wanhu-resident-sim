# 网页故事审查器

## V0.1 目标

第一版不是完整居民模拟器，而是一个可部署到 Vercel 的故事审查器，用于验证：

```text
Story Markdown → 标准数据 → 网页逐节点展示
```

核心用途：

1. 以玩家视角检查故事是否能在隐藏分支标题时仍然自然理解。
2. 顺序审查全部故事，避免遗漏。
3. 随机抽取故事和分支，感受未来游戏中的事件体验。
4. 快速切换分支，检查第二、第三阶段的因果与时间。

## 页面结构

页面中央只有一个主要故事窗口：

```text
故事标题
节点阶段 · 节点时间
节点标题
正文

[上一节点] [下一节点]

故事 12 / 86
[上一个故事] [重抽分支] [下一个故事]
```

顶部提供：

- 顺序 / 随机故事模式。
- 游戏 / 审查模式。

审查模式额外显示：

- Story ID。
- 来源文件。
- 分类。
- 当前 Branch ID。
- 全部分支切换按钮。

## 游戏模式

游戏模式模拟玩家真实看到的内容：

```text
第一阶段
  ↓
随机选中一个分支
  ↓
该分支第二阶段
  ↓
该分支第三阶段
```

不会一次展示所有分支。

## 审查模式

审查模式允许直接切换 `b01 / b02 / b03 / ...`。切换后仍保持当前阶段，便于横向比较同一个故事的不同分支。

## 故事切换

### 顺序模式

严格按编译结果中的排序前后切换，并显示 `当前 / 总数`。

### 随机模式

“下一个故事”随机选取另一个故事。故事内部仍随机选一个分支。

## V0.1 暂不包含

- 居民姓名生成。
- 年龄 / 性别 / 职业 / 家庭条件筛选。
- 故事权重与居民 Eligibility 匹配。
- 真实游戏日历推进。
- 属性与关系 Effects。
- Unity 导出。

这些功能在 StoryDocument 与展示链路稳定后逐层加入。
