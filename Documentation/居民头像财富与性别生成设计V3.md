# 居民头像财富与性别生成设计 V3

## 目标

Web 头像系统继续只验证玩家体验，不提前设计 Unity Save、Blob 或最终 Runtime 数据结构。

本阶段取消“职业决定服饰”的方向。头像首先表达一个居民的年龄、性别与家庭生活条件，而不是把职业做成角色职业图标。

当前外观主要由四个事实驱动：

```text
Gender
LifeStage
Household.WealthTier
Household.PresentationStyle
```

职业仍然存在于居民玩法中，但不再用于挑选服装、官帽或所谓职业制服。

## 家庭财富

财富属于 Household，而不是每个居民独立随机。这样同住家人天然具有接近的生活条件和衣着质感。

当前四档：

```text
poor         贫寒
plain        普通
comfortable  殷实
wealthy      富裕
```

财富影响的是候选权重和资源质量，而不是固定制服：

- 贫寒：粗布、褪色、单层、附件少；
- 普通：朴素常服、少量整洁配色；
- 殷实：叠领、较好的布料与较丰富配色；
- 富裕：细布、更多层次、簪/冠帽等附件概率上升。

同一财富层内部仍必须保持明显差异。

## 生活讲究程度

财富不直接等于华丽。Household 同时具有轻量 PresentationStyle：

```text
practical  实用
tidy       整洁
refined    讲究
```

这允许出现：

- 富裕但穿得低调；
- 家境普通但收拾得很整洁；
- 殷实家庭中更讲究衣着的人群。

Web 原型当前让同一 Household 共用 WealthTier 与 PresentationStyle，先验证家庭视觉一致性。

## 女性轮廓

V2 已证明只在头顶增加发髻不足以形成稳定的女性辨识度。V3 把女性发型重点转向整体轮廓。

第一批发型包括：

```text
长直发一 / 二
长发后束
单侧垂发
单辫
双辫
盘髻
低髻
年长收束发
```

关键美术规则：

- Back Hair 可以延伸到肩部，不局限在头顶；
- 长发必须在 48×48 缩略图仍能改变外轮廓；
- Front Hair 只负责发际线和脸侧少量垂发，不承担整张头发；
- 女性辨识主要来自发型轮廓、脸型轻微差异与服装肩领，不通过夸张五官实现；
- 女性仍与男性共用 PortraitRig 锚点体系。

## 职业不再驱动外观

明确删除以下思路：

```text
木工 → 工匠服
商贩 → 商服
书生 → 长衫
官员 → 官帽 / 官服
```

这些会让头像变成职业图标，而且会把泛中国古代的居民视觉过早绑定到具体身份制服。

新的 Resolver：

```text
Resident
├ Gender
├ LifeStage
└ Household
   ├ WealthTier
   └ PresentationStyle
        ↓
Appearance Candidate Filter
        ↓
Face / Hair / Brow / FacialHair
Headwear / Outfit / Palette
        ↓
PortraitRig
        ↓
Final Portrait
```

职业可以继续影响居民活动、故事、工作地，但不进入头像服饰候选池。

## Portrait Lab V4

入口仍为：

```text
/?view=portraits
```

筛选维度：

```text
性别：全部 / 男 / 女
财富：全部 / 贫寒 / 普通 / 殷实 / 富裕
状态：全部 / 实用 / 整洁 / 讲究
年龄
脸型
诊断
```

前 8 个覆盖样本固定包含：

- 四种财富档的女性；
- 富裕老年女性；
- 贫寒、殷实、富裕男性。

这样每次打开实验室都可以直接比较财富层次和女性长发轮廓。

职业名称仍显示在卡片中，只用于说明居民本身是谁；它不参与头像生成。

## 与未来 Unity 的关系

迁移的是语义和美术约束，不迁移 Web SVG 代码：

```text
WealthTier
PresentationStyle
AppearanceDNA Stable IDs
PortraitRig / attachment rules
Portrait Art Kit layer rules
```

Unity 可以重新把这些语义映射到 Sprite、Atlas、Mesh、Material 或 3D 模块化居民。

## 当前验收标准

1. 随机 64 人零 PortraitRig 硬错误；
2. 女性不会生成胡须；
3. 女性覆盖样本至少 4 个明显使用长发、垂发、辫子或盘发轮廓；
4. 财富四档都有覆盖样本；
5. 贫寒样本不会穿富裕细布整衣，富裕样本优先叠层/细布服装；
6. 头像实验室不再出现“官署”作为外观筛选维度；
7. 同一职业可以因为财富不同而呈现完全不同的衣着层次；
8. 财富相同的居民仍保留大量脸型、发型、配色差异。
