# Portrait Style Exploration V5

## 目标

V5 不再把“美术风格”理解为同一张人物模板上的配色、描边或材质变化。

这一阶段只比较四套真正独立的美术体系：

- 强化套色木刻
- 壁画化重彩
- 白描人物谱
- 绢本设色小像

同一个 Golden Resident 只共享姓名、年龄、性别、财富等身份语义。四套 Style Pack 可以拥有不同的脸型比例、五官位置、姿势、侧转方向、头发概括方式和服装构图。

## 核心原则

### Style Pack 必须独立

每个方向拥有独立的 Geometry System。

不再要求：

- 同一 Face SVG；
- 同一 Hair SVG；
- 同一正面姿势；
- 同一眉眼位置；
- 同一肩颈比例。

只要求四张图仍然能被理解为同一类居民身份样本。

### 强化套色木刻

- 正面或近正面；
- 粗黑轮廓；
- 有明显刀刻感的直线与斜线；
- 有限套色；
- 允许夸张脸宽、下颌、眉眼和胡须；
- 小尺寸首先靠黑白关系与轮廓识别。

### 壁画化重彩

- 三分之四侧脸；
- 长眼线、扁平鼻口；
- 赭石、石绿、土黄等矿物色倾向；
- 发式与衣纹更装饰化；
- 允许左右翻转构图；
- 不追求现代写实比例。

### 白描人物谱

- 纸色背景；
- 线条主导，极少填色；
- 侧转人物谱式构图；
- 发丝、衣褶、眉眼均用不同线条节奏表达；
- 留白本身是画面结构的一部分。

### 绢本设色小像

- 更自然的人体比例；
- 轻微侧转；
- 柔和罩染；
- 线条更细；
- 通过面部明暗、发髻体积和层叠衣领表达身份；
- 更接近温润的人物册页，而不是 UI 图标。

## 自动验收

Style Lab 页面仍然使用 8 个 Golden Residents，但只展示 4 个 V5 方向。

CI 强制检查：

- 8 个居民；
- 4 个 Style Pack；
- 32 张主比较头像；
- 同一行四张图 identity-source 相同；
- 同一行四张图 art-system 必须全部不同；
- 全部背景无 Halo；
- 96 / 64 / 48px 小尺寸都存在；
- 每个风格单独输出审查图。

## 选择标准

重点不是单张精致度，而是：

1. 哪个方向最像真正独立画师完成的成套作品；
2. 哪个方向在 48px 仍然能稳定识别；
3. 男女、年龄、财富是否不会被模板化；
4. 同屏数十居民时是否容易扫读；
5. 是否符合《万户天工》的泛中国古代城市语境；
6. 未来扩展到数百居民时，美术成本是否可控。
