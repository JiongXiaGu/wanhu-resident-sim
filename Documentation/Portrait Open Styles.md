# 开放头像画风候选：21岁女子 / 32岁男子

## 本轮目标

入口：`/?view=portrait-style-directions-v2`。首页和旧实验页都有“头像画风候选”入口。

只有年龄与性别主题固定：21岁女子、32岁男子。每一种画法自由设计人物，不要求同一张脸、同一发型、同一肤色、同一服装、同一表情或同一朝向。不强行添加中国古代服饰、发冠或青玉配色，不再把世界观符号放在审美选择前面。

年龄是本轮设计设定，不是依据图片推断真实人物年龄，也不是自动年龄识别的结果。

## 四种画法 / 八张独立位图

| 编号 | 方向 | 本轮观察重点 | 与其他方向拉开的方式 |
| --- | --- | --- | --- |
| A | 现代赛璐璐 | 动画脸部、细线、发丝和衣装块面 | 不采用写实鼻口与油画式皮肤 |
| B | 厚涂人物画 | 成人骨相、笔触、自然侧光 | 不画动漫大眼，不靠描线表达整个脸 |
| C | 柔光三维感 | 体积、柔和材质、独立五官塑形 | 不用粗黑线；与B相比更少笔触、更平滑 |
| D | 漫画块面 | 黑色形状、强轮廓、构图和留白 | 不使用A的细发丝，也不追求B/C的平滑光照 |

它们不是同一母图的滤镜、换色、粗细描边版本。A女子、B女子、C女子、D女子是独立人物设计，男子亦然。原始图片各有不同姿态、面容、头发与服装。

## 制作方式与真实性

这次不继续手写几百条相近的 SVG path。画稿通过原生图像生成工具 `image_gen` 制作，使用上述四种独立媒介目标与两个年龄主题，得到无文字、无按钮、无图表的 4×2 人物素材板，再按格裁切为八个独立资源。

- 原始素材板：1536×1024；每格四周去掉2像素分隔边。
- 网页资源：每张 256×342 的 AVIF；全部图片采用同一裁切与编码流程，没有按画风添加不同滤镜。
- 导出给审查的 PNG：由已入库 AVIF 解码，保持256×342，不虚标高分辨率或透明底。
- 全部素材带中性背景，不是已抠图的 Face/Hair/Outfit 分层资源。
- C 是“画面有三维感”的位图概念，不是已经制作了三维模型、骨架或 BlendShape。
- 参考网站只提供外部资料链接；没有把官方角色图打包进仓库。

**这页没有捏脸、换发型或换服装功能。** 选中另一幅完整画稿只用于选择画风，不能把这种切图称为头像自定义已实现。旧版真正可组合的实验仍在原路由中保留。

## 可以操作什么

- 四组总览与单组大图切换。
- 每种画法的21岁女子、32岁男子均有96/64/48 CSS px方形头像裁切。
- 身份栏内切换男女样本，并切换明/暗世界背景。
- 隐藏画风名称，减少名称暗示；保留编号方便选择。
- 全部原稿统一灰阶诊断，用于观察线条、明暗和脸型。它只是审稿功能，不是第五种画风。
- 加入/移出候选、本浏览器记忆、导出选择JSON、清除本页候选。
- 每组提供官方参考资料、后续捏脸验证路线与风险。

存储键：`wanhu.portrait-open-styles.v1`。严格校验选项、去重和版本；不读取或改写旧版 Composer / Anime / Modern Anime 配方。

## Actions review

保留原有居民故事链、正式头像、Composer、Anime、Modern Anime的所有检查；在同一 Resident Visual Review 末尾追加 `scripts/capture-open-style-review.mjs`。

自动检查：

- 八份独立资源的Git blob哈希、图像尺寸和解码；哈希不同不代表美术一定不同。
- 四组总览确实包含两个年龄主题，资源没有交叉引用成同一张图。
- 原色和统一灰阶模式的资源身份不变，隐藏名称不改变图片。
- 四种画法 × 两个主题 × 96/64/48，共24个原尺寸样本。
- 四种画法 × 两个主题 × 明暗场景，共16个身份栏试装截图；Panel颜色不因世界明暗改变。
- 鼠标/键盘切换、候选保存与清除、实际JSON下载、损坏存储恢复。
- 旧保存键不变，1600/390/320px宽度无横向溢出，浏览器无错误。

截图和PNG在 Artifact 的 `open-styles/` 下，保留原始PNG，不进入旧的缩图脚本。必须下载并打开：总览、去名称灰阶总览、每组两个人物、界面试装、小尺寸、移动端。人工检查风格是否拉开、年龄气质、五官和头发是否自然、暗色UI是否协调；不能用CI或哈希代替这一步。

本页不做自动美术排名，不把图像生成产物标成“手工绘制”，也不把编码分辨率或样本数称为制作完成度。

## 选择之后

先选出一到两个方向，再每组做两张不同脸、三种共享发型、三套共享服装、四套协调表情的小型自定义验证。只有那一步通过，才决定采用分层绘画、矢量重绘或三维捏脸烘焙。

正式Runtime仍冻结：五字段DNA、六个PortraitFrame和五层RenderPlan均未修改。没有新增正式资产、修改游戏居民数据、重做序列化或依赖Vercel。
