# Portrait Style Exploration V3

## 目标

这一阶段不继续优化 Portrait Art Kit V2 的参数化脸，而是先确定《万户天工》居民头像应该采用哪一种正式美术语言。

Style Lab 使用 8 个固定 Golden Residents。每个人的年龄、性别、财富、Face Base、Hair Asset 都固定，只切换美术风格。这样横向比较时，判断的是风格本身，而不是随机人物差异。

页面入口：

~~~text
/?view=portrait-styles
~~~

## 四个候选方向

### Paper Cut Collage V3

使用无描边大块面与明确的前后层关系。Face Base、Hair Front、Hair Back、Outfit 都视为手工资产，而不是由脸宽、下颌宽等参数实时生成。

优势是生产快、结构清楚、最容易在 Unity 中重新映射为 Sprite 或其它正式资源。

### Ink Flat

用墨线承担五官、脸部与服装结构，低饱和淡彩只承担色块。

方向更接近古代人物志、地方志插图和轻设色线稿。小尺寸依靠线条节奏保持人物身份。

### Woodblock

使用粗黑轮廓、有限套色和刻线纹理。

优先追求 48px 到 96px 的辨识度，而不是大图细腻度。该方向允许适度夸张脸型、眉眼、发型和衣领结构。

### Painterly Simple

使用更柔和的明暗、少量渐变和局部笔触，靠脸部体积和材质差异提高成品质感。

这个方向最接近正式角色插画，但制作和扩展成本也最高。

## Golden Residents

固定八个人：

- 青年男子 / 贫寒
- 成年男子 / 普通
- 中年男子 / 殷实
- 老年男子 / 富裕
- 青年女子 / 贫寒
- 成年女子 / 普通
- 中年女子 / 殷实
- 老年女子 / 富裕

每个人都有独立手工 Face Base 路径与 Hair Asset。四个风格不能自行改变人物身份资产。

## 强制约束

- 背景必须干净，禁止人物脑后光环、圆形背光和类似 Halo 的构图。
- 同一行四个头像必须使用相同 Face Asset 与 Hair Asset。
- 页面必须同时展示 96px、64px、48px 实际游戏尺寸。
- Style Lab 不以 V2 的 faceScale、jawScale、eyeSpacing 等参数作为 Face Base 的主要生产方式。
- 先选风格，再扩资产数量。当前阶段不追求 64 人随机覆盖。

## 选择标准

判断顺序：

1. 男女是否不依赖胡须也能成立。
2. 青年、成年、中年、老年是否能被读出。
3. 同一风格下八个人是否像八个不同的人。
4. 48px 下主要身份特征是否仍然存在。
5. 贫寒、普通、殷实、富裕是否通过衣领、层数、完整度表现，而非职业制服。
6. 批量生产数百居民时，成本是否可接受。
7. 是否符合《万户天工》的古代城市居民语境。

Style Lab 只是方向选择工具。被选中的风格才进入下一阶段的正式资产库扩充和 Game Asset Approved 流程。
