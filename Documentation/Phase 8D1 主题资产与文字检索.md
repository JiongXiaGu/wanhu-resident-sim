# Phase 8D1：主题资产与文字检索

## 范围与承接

接手基线：`7ba57695c392f14d598e818beadecff877dd52f9`。用户认为 8B2 基础画法基本可行，批准 8D1-A 与 8D1-B 一起执行，并要求每个美术资产有文字描述，便于检索。认可继续扩库不等于所有新稿已经最终定稿。

8D1-A 为常服、劳作；8D1-B 为商铺、行旅。每主题新增 4 个 Hair ID、4 个 Outfit ID，合计 32 个新 ID。按适用成年男女框架共 20 份头部造型、24 份衣装画稿；不是新增 44 个 ID。儿童和老年沿用 8B2，不把成年素材缩小复用。

当前可选总数为 **6 Face / 46 Hair / 40 Outfit / 8 Expression**，合计 100 个资产。成年女性可选 22 Hair / 22 Outfit，成年男性 19 Hair / 22 Outfit；其他 Frame 不变。不能把全库 Hair × Outfit 的乘积宣称为每个 Frame 的真实组合数量，组合数由 Catalog 按 Frame 计算。

## 文字资产契约

每个玩家可选资产必须有稳定 ID、中文名称、中文 `description` 与 `tags`。`note` 保留为卡片短注；完整描述说明形状、叠层、与相近旧款的差异和小尺寸识别重点，不能只写“好看”“高级”等评语。

`catalog.ts` 保管原有 68 个可选资产的文字；`theme-catalog.ts` 保管本批 32 个资产。两者汇合到唯一的 chibi Catalog，UI 与检索只读取 Catalog，不再维护手写搜索表。旧十个 compatibility-only ID 仍只是解析入口，不属于可选画稿，不回到搜索或 Random。

文字与关键词不进入 Recipe、LocalStorage 保存记录、正式 DNA 或居民故事。修改文案不修改 ID，不使旧配方失效。Actions 中的 `asset-descriptions.json` 是当次 Catalog 的只读导出，不是需要手改的第二权威。

## 工坊检索

现有部件栏增加一个搜索框和所选资产说明，不改变三栏布局或年龄/性别入口。搜索只在当前 Frame、当前分类和当前“仅已重画”过滤结果中进行。支持 ID、名称、短注、完整描述、关键词；做 Unicode NFKC 归一化与不区分大小写匹配，空格分词为 AND。

例如选择成年和头发，搜 `8D1` 看本批适用造型；搜 `8D1 行旅` 只看本批行旅造型；搜 `斗笠`、`斜襟` 或完整 ID 查具体资产。名称或关键词有重复是允许的，不依赖显示文字做唯一键。

搜索不改头像、不标记脏草稿、不保存。切分类清空搜索；真正提交对象/Frame 切换后清空搜索，取消草稿确认不偷偷切上下文。无结果时有清除搜索与筛选入口，不替玩家选择另一个资产。

“随机本类”遵守当前搜索结果；没有其他候选则禁用。原“随机搭配头发与衣服”仍是全搭配操作，不受文本搜索影响，但保留原“仅已重画”限制，界面有明确说明。

历史 `isReworkedSample` 清单不把新增当作重画。新卡片显示“本批新增”，历史卡片显示“已重画”，两者都不表示最终认可。开着“仅已重画”再搜 `8D1` 会为空，清除筛选即可。

## 画稿与源文件职责

`theme-hair.ts` 绘制本批成年头部造型；`theme-outfits.ts` 绘制本批成年衣装。原 `hair.ts` / `outfits.ts` 只增加显式分发，原有儿童、老年与成年画稿不改。Head Frame、Face、Expression、正式 Portrait Renderer 均不动。

头发不读取 Face。帽巾完整前帽身在 HeadwearFront，后结/布尾在背层；全包帽下只保留被帽身覆盖的额边与鬓发，不套上一个外露的完整裸发顶。无帽编辫/发髻允许共用固定额发笔画，但外轮廓需有可辨差异。

衣装继续遵守 base / collar / overlay / detail，base 与 collar 必须存在。外褂是真实完整的前片，内外领有清楚遮挡关系；胸像底部延伸出画布，不硬塞腰带、裙腰或围裙吊带。

本地静态看图后修正过：斗笠檐上外露的发顶、窄缘短襦漂浮小条、折领铺衫外露过长的内领，以及披帛不连续的折面。只调整作者路径，没有用遮罩或自动适配补洞。

## 审查与证据

纯画稿短循环使用真实 Renderer 输出四主题及男女共用款图板，人工检查 320 / 96 / 64 / 48px。正式交付仍必须在同 SHA 跑 Build 和 Resident Visual Review，下载 Artifact、核对源码和 `avatar/source-commit.txt`，实际打开诊断与真实工坊截图。用户不接收压缩包不等于执行者跳过 Artifact 审查。

`capture-avatar-theme-assets.mjs` 复用 `renderBoards`，只补本批增量：44 次实际新素材点选、100 份文字完整性、搜索匹配/组合筛选/空结果/随机、成年男女独立保存刷新、新 ID 的 JSON 往返、真实居民应用和身份日期不变。头发补 1640 个额角弧线位置的 2 单位余量抽样；衣装检查 24 份作者层与版型标记。

原 8B2 基线的 88 份固定配方逐字节不变；新款几何签名与同 Frame 其他选项比较，拦截路径完全相同而只换颜色的副本。签名不同和弧线抽样都不能证明审美独特性或所有像素无缺陷，仍须看图。

原 Catalog 全组合、Hair 跨 Face 不变、Coverage、腮红、兼容回退、六样板保存、延迟导入、冲突/失败、居民连续性和正式 fallback 继续运行。旧 8B2 阶段的点选与冻结断言限定历史明确清单，新加 ID 则由 8D1 专项与通用组合审查共同覆盖，不删除旧断言来凑 PASS。

通用素材密度上限调整为每类最多 22，配合成年搜索和原滚动列表；8D1 增量审查另外检查儿童、老年仍不超过原 12 项边界。之后继续扩量时，应先审查浏览体验，不无限抬高上限。

Artifact 目录 `avatar/phase8d1/`：`common.png`、`labor.png`、`merchant.png`、`traveler.png` 为全部适用成年 Frame 的主题诊断；`overview.png` 是组合总览；`faces-and-collars.png` 检查六脸型。`studio-<theme>-<frame>.png` 共八张真实工坊，`bound-resident.png` 为真实绑定界面。机器报告为 `theme-assets-review.json`，文字导出为 `asset-descriptions.json`。

本地静态验证已经确认 88 份旧稿不变、100 份描述可检索、44 份新几何签名非完全重复，以及 1640 个弧线位置的填充余量。完整浏览器和最终 main 结果以对应 SHA 的 Actions / Artifact 为准，不用本地静态结果冒充。
