# 现代国风二次元人物实验

## 定位

入口：`/?view=portrait-modern-anime-lab`。首页、原版 DIY、上一版二次元和正式工作台都有“现代国风 · 新画风与换装”入口。

用户需要的是接近现代二游审美、带中国古代设计语汇的头像，不是旧网页卡通头像继续放大眼睛。本实验重新绘制面部轮廓和眼型、细线与虹膜、长发分束、衣料层次和配饰，不导入旧 Anime / Composer / 正式 Portrait 的美术。

这是 **一套新视觉系统、三组可编辑搭配**，不是三套独立画风，也不是三张绑定服装的完整角色图片。晴岚、霁夜、丹华分别展示明快常服、冷调长衫和国风礼装。它们都是同一个分层渲染器生成的配方，载入后每个部件仍可独立修改。

《原神》《鸣潮》只描述用户的审美目标；本仓库没有复制其角色、服装纹样或游戏资源，也不把原型完成宣称为达到这些游戏的成品制作水准。最终画风仍待用户选择。

## 当前内容

- 成年女性、成年男性各 3 个完整面容，共 6 个面容资产：清澄、疏朗、明锐。
- 6 套协调表情预设：平静、浅笑、欣喜、笑意、认真、低落。
- 3 种发型：流云半束、高束长尾、侧编挽髻；男女后发分别绘制。
- 4 个帽饰选项：无头饰、玉簪、束发冠、软脚幞头。
- 3 套共享服装：交领常服、层襟长衫、云纹礼装。
- 肤色、发色、衣装配色各 3 组。
- 透明 SVG / 1024px PNG 导出，配方导入/导出、浏览器保存、分享链接。

不同脸共享同一个 Frame 的发型、帽饰和服饰。同脸切换表情不改变脸型，换脸不会替玩家换衣服。表情定制仍指选择预设，不是任意拼眼鼻嘴。

旧 16 脸 Composer、旧 Anime、历史画风研究及正式居民 Runtime 保留。没有把这一套候选美术默认定为正式方向。

## 图层和画布

```text
BackHeadwear

HairCrown
Neck
Outfit
FaceBase
Expression
FrontHair

```

画布固定为 `0 0 512 512`。不同面容与配件按这个作者坐标直接绘制，不存在按脸缩放头发、自动对齐或补丁偏移表。固定镜像与衣装纹样的局部变换是绘画手段，不是 Runtime 适配引擎。

SVG 使用自包含的渐变定义、色块与细线，不依赖外部图片、字体、CSS 或位图角色图。虹膜和高光按眼白内的轮廓作画，不依赖遮罩裁切。导出中的 `data-layer` 便于检查部件，但实验的九层画布并不是正式五层 RenderPlan 的替代契约。

三项不变量：

```text
换发型 / 帽饰 / 服装 → FaceBase 和 Expression 不变
换表情 → FaceBase 与其他衣装图层不变
换脸 → 衣装、头发、帽饰、颈部不变；眼型改用该脸设计
```

幞头会暂时收起顶部发髻，保存的发型 ID 不变。摘下幞头恢复原图。玉簪与束发冠保留完整发髻。由于遮挡，戴帽时可见的发型差异可能减小，不能把每个参数组合算作肉眼独特人物。

## 美术目标和小尺寸取舍

脸部使用更轻的轮廓线、较长的脸部比例和局部上眼线；嘴型围绕 x=256 固定中线作画。头发通过大束剪影、内层暗面、局部反光、少量细发丝组织，而不是只在圆帽外壳上加几条线。

中国题材主要来自束挽发、玉簪/发冠/幞头、交领/层襟、云纹、玉件和衣装层次，不使用面部刻板印象。这里是泛中国古代的角色设计，不是朝代服饰复原。

近景可显示发丝、玉饰和纹样；到 48px 时应优先依赖面容、发型剪影、衣领结构与色块。细节多不等于小图更好辨认，表情居中也不等于表情已经达到审美要求。

源码在 `Web/src/portrait-modern-anime-lab/`：model 管选项与配方，art 管美术，render 管层序和导出，ModernAnimeLab 管页面，modern.css 只作用于 pm-*。

## Review

Resident Visual Review 保留原有居民生活链、正式头像、Composer、Anime 的全部测试，在其后追加 `scripts/capture-modern-anime.mjs`。

新检查包含：

- 2 Frame × 3 Face × 6 Expression × 3 Hair × 4 Headwear × 3 Outfit = **1,296 个基础几何组合**的合法 SVG 与双向图层独立性。
- 6 个独立面容、36 个面容/表情样本、72 个发型/帽饰样本、18 个衣装样本。
- 嘴型实际 bbox 围绕 x=256；虹膜及高光抽样位于实际眼白内。
- 戴帽/摘帽恢复同一 SVG、键盘选择表情、锁身份随机、512 种子目录覆盖。
- 实际透明 PNG/SVG/JSON 下载、有效/无效导入、刷新恢复、分享链接编辑和旧保存键未改写。
- 原始 96/64/48 CSS px、1600/390/320 页面宽度、深肤银发和暮色背景。

原始截图在 Artifact 的 `modern-anime/`，不经过旧预览缩图。`exports/` 是当前渲染器现场输出的 36 份 SVG/PNG 组合样本，不是 Runtime 的固定整图资源库。

**CI 绿色、样本数、嘴型居中和几何检查都不代表美术达到目标。** 必须下载并实际打开三组搭配、男女面容、表情、帽饰/衣装矩阵、小尺寸和移动端截图。存在明显问题就先修正再推进 main；main 自身也必须重新运行并下载核对。

## 不在本次范围

儿童/老人、身份随年龄连续变化、任意五官编辑、动态口型、游戏情绪自动驱动、Unity 导入和量产资产预算均未完成。正式五字段 DNA、六个 PortraitFrame 和五层 RenderPlan 不变。先确认美术方向，再讨论如何重画成正式生产 Frame，不借实验扩张冻结 Runtime。
