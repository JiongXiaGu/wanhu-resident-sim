# Portrait Style Exploration V4

## 目标

V4 把头像方向探索从 4 种扩大到 8 种。仍然使用同一批 8 个 Golden Residents，人物身份、年龄、财富、Face Base 与 Hair Asset 不变，只改变美术语言。

页面入口：

```text
/?view=portrait-styles
```

## 八个候选方向

### 1. Paper Cut Collage V3
无描边大块面、剪纸式层叠。生产效率高，最容易转成正式 Sprite 资产。

### 2. Ink Flat
墨线承担结构，低饱和淡彩负责色块。偏古代人物志与轻设色线稿。

### 3. Woodblock
粗轮廓、有限套色、刻线纹理。优先保证 48px–96px 的辨识度。

### 4. Painterly Simple
柔和明暗和少量笔触，偏正式角色插画，成品质感高，但资产成本最高。

### 5. Restrained Chibi / 克制 Q 版
头部约放大一档、肩部收窄、五官简化，但不使用幼儿比例、超大眼或现代萌系表情。

目标是测试城市模拟 UI 中更亲和、更易扫读的头像比例，同时保留成年、老年、财富和性别信息。

### 6. Baimiao / 白描人物
纸色底、细线描、极少填色。参考传统白描与人物谱的视觉原则，不复刻任何具体作品。

该方向测试最低色彩复杂度下，人物是否仍能依赖线条、脸型和发式成立。

### 7. Clay Figurine / 陶俑泥塑
低彩陶土、浅浮雕体块、轻微颗粒。强调“实体人物小像”而非二维图标感。

该方向适合观察《万户天工》是否可以采用更古朴、器物化、博物志式的居民表现。

### 8. Folk Print / 民俗年画套色
更明显的红、土黄、墨色套色和装饰线，强调城市烟火气与民俗感。

需要控制饱和度，避免变成节庆限定皮肤或网页游戏头像。

## Golden Residents

固定八个人覆盖：

- 青年男子 / 贫寒
- 成年男子 / 普通
- 中年男子 / 殷实
- 老年男子 / 富裕
- 青年女子 / 贫寒
- 成年女子 / 普通
- 中年女子 / 殷实
- 老年女子 / 富裕

同一行的八张图必须复用同一个 Face Asset 与 Hair Asset。

## Q 版的边界

Q 版不是“可爱化所有居民”。

允许：

- 头部相对放大；
- 肩宽与躯干减少；
- 五官线条简化；
- 发型、胡须、年龄特征更加图形化。

禁止：

- 所有人幼儿脸；
- 超大高光眼；
- 腮红承担女性识别；
- 老年人被画成儿童老人；
- 财富靠皇冠、金链、职业制服等符号直给。

## 强制审查

CI 固定检查：

- 8 个 Golden Residents；
- 8 个 Style；
- 64 张主比较头像；
- 每个居民八种风格保持相同 Face/Hair 身份资产；
- 所有背景无 Halo；
- 96 / 64 / 48px 都可查看；
- Q 版单独输出小尺寸审查图。

## 选择标准

不要只选“单张最漂亮”的。

优先比较：

1. 48px 和 64px 是否仍能识别人。
2. 男女是否不依赖胡须成立。
3. 成年、老年是否不会在 Q 版里被抹平。
4. 八个人是否真的像八个不同的人。
5. 财富层次是否通过衣领与服装完整度表达。
6. 同屏几十人是否容易扫读。
7. 扩到数百居民时，美术生产成本是否可接受。
8. 是否符合《万户天工》的泛中国古代城市语境。
