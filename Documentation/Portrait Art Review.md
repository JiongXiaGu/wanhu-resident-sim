# 新美术页的视觉评审规则

本页规则仅适用于 `/?view=portrait-art-reboot` 的方向比较，不改变生产 PortraitFrame。

## 深色底不是把人物一起压暗

页面控件底色 `--par-art` 与人物衬底 `--par-avatar` 分开维护。深色页面可以保持较低明度，但透明头像的衬底必须与深发色保持可见差异；不能让黑发只剩额头一条边线。

当前采用中间明度的灰绿头像底，不修改原画发色，不用额外硬描边掩盖问题。图像背景不透明的 01 组仍保留原画纸底，不能冒充通过了透明背景混合。

自动测试用一组代表性深发色和头像衬底作 2.5:1 的项目自定预警。它不是所有插画的无障碍认证，也不能替代查看 48 / 64 / 96 px 截图。

## 方向判断与生产批准分开

三组用于判断插画、平面绘本和体积小像的方向差异。插画组需要重新做生产分辨率与完整冠发构图；绘本组需要更多脸型、年龄与性别；小像组必须单独判断玩偶感是否适合游戏。

独立评审页可以进入 main，不等于这三组资产已经通过生产验收；任何候选都不应自动替换正式 Runtime 或被直接宣布可量产。
