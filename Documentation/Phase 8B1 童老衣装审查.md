## 截图后继续修正

| 发现 | 根因和处理 |
| --- | --- |
| 老年部分发型左上方有一小块褐色描边 | 五个固定Coverage点全通过，但两点之间的Head Frame轮廓仍露出。静态重画老年外包络，并给儿童总角额角增加少量描边余量；上头型、Face和内部疏发发际不变。 |
| 老者侧髻像多出一只耳朵 | 圆髻紧贴真实耳位，缩小时两者混在一起。移至耳后下方，改为收束折面，取消围着耳朵的同心圆轮廓。 |
| 第一轮旧新对照不能严格隔离改动 | 相同Recipe在新旧画稿中会同时换掉Hair与Outfit。改为只替换旧Hair四层或Outfit层，其他图层字节相同；对照仍是诊断图，不注册第二套Pack。 |

补充审查只读取SVG：对本批23份发型的固定上头型两段二次曲线采样，各41个位置，合计1886个位置，并检查上下左右2个画布单位余量。它不用于运行时变形，不新增Face依赖、offset、solver或裁切。原220个Coverage点检查仍保留；新采样不是“数学证明所有像素都正确”，人工仍须看实际轮廓。

## 当前美术观察与限制

| 项目 | 已改善 | 尚不能声称完成 |
| --- | --- | --- |
| 儿童发型 | 双髻、发环、垂髫、侧辫、半束与平短额发不再全部共用碎刘海 | 双髻与总角仍同属双结轮廓；半束尾发在正面被部分遮住，不保证48px全部一眼区分 |
| 老年发型 | 高低髻、后拢长发和退后发际有可比较的大形，额角修正后不再出现首轮褐色突出 | 老年眉眼仍沿用8A较收敛的画法，本批不重画Face；不是全套老年面部定稿 |
| 儿童衣装 | 交领、团领、对襟、夹棉与锦边罩衣有不同领口，帮工衣取消围襟吊带 | 方领与扣结仍是简化候选，不宣称具体朝代服制复原 |
| 老年衣装 | 常服、罩衣、团领、劳作、夹棉、对襟的领口/叠穿有变化，无裙腰挡板 | 男女共享款式差异主要在肩形，不把24份适用画稿说成24种完全独立设计 |
| 小尺寸 | 96/64px可比较领型与头部轮廓，48px主色块仍可读 | 小系结、发丝和补缀不要求在48px完整可见，不靠这些细节定义新款 |
| 编辑器 | 四Frame全部素材可点选；已重画筛选涵盖8A与本批；未保存提示和对象隔离有效 | 不在这次改动中重排整个编辑器；“已重画”不是最终认可徽章 |
